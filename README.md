### 🤖 [BChat — AI-Powered WhatsApp CRM](https://bchat.unitrixsolutions.com)

> A multi-tenant customer-support and sales platform combining WhatsApp messaging, AI chatbots, and CRM workflows.

- 🧠 Routes requests across **OpenAI, Gemini, Anthropic, and OpenRouter**.
- 💬 Supports **WAHA** and **Evolution API** for WhatsApp messaging.
- 🔀 Includes a visual conversation-flow builder, knowledge base, contact management, broadcasts, and sales pipelines.
- 🔐 Uses PostgreSQL row-level security for tenant isolation and server-side encryption for API keys.
